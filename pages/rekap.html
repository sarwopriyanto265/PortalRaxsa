📋 Cara Update Data Rekap

Data rekap diambil otomatis dari Google Sheets. Untuk menambah atau mengubah data, klik tombol di bawah untuk membuka spreadsheet sumber.

  1. Klik tombol "Buka Google Sheets" di bawah untuk mengedit data.
  2. Tambah baris baru dengan kolom: name, vendor, url, description, icon
  3. Isi kolom vendor untuk mengelompokkan card (contoh: Finance, Produksi, Marketing, Penjahit).
  4. Kolom icon opsional: folder, money, users, box, image, monitor, file
  5. URL di kolom url harus dimulai dengan https:// agar bisa diklik.
  6. Setelah selesai edit, refresh halaman ini untuk melihat perubahan.
Buka Google Sheets
💡 Tombol di atas akan aktif setelah lu paste URL Google Sheets (mode edit) di file js/rekap.js bagian REKAP_SHEET_EDIT_URL.
